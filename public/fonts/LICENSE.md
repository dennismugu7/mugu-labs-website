# Poppins

The font files in this folder are subsets of **Poppins**, designed by Indian
Type Foundry, Jonny Pinhorn and Ninad Kale, and released under the
**SIL Open Font License, Version 1.1**.

The OFL permits use, study, modification and redistribution — including the
subsetting done here — provided the fonts are not sold on their own and the
license travels with them.

- Family: https://fonts.google.com/specimen/Poppins
- Source: https://github.com/itfoundry/Poppins
- Full license text: https://openfontlicense.org/open-font-license-official-text/

Reserved Font Name: none declared by the original release.

Subsetted for this site with `scripts/build-fonts.py` (Latin ranges only).
Replace these files with the upstream originals at any time — the `@font-face`
rules in `styles/fonts.css` expect the same filenames.
